# ضع ملف APK الأصلي هنا

ارفع ملف `.apk` إلى هذا المجلد (بالاسم الذي تريد) ثم ادفعه إلى الفرع
`arena/01a0f4bf-abbas` — أو ارفعه من واجهة GitHub مباشرةً عبر
**Add file → Upload files**.

عند وصول الملف يعمل سير العمل `.github/workflows/apk-repackage.yml` تلقائيًا:

1. يفكّ الـ APK بـ `apktool` (دون إعادة ترجمة أي شيفرة).
2. يغيّر معرّف التطبيق إلى `com.almlkaide.kaypro`، ومعه الأذونات المخصّصة
   وسلطات مزوّدي المحتوى (authorities) و`taskAffinity`.
3. يُبقي أسماء أصناف المكوّنات كما هي لأنها موجودة فعلًا داخل الـ DEX.
4. يُعيد البناء والمحاذاة والتوقيع بمفتاح debug.
5. ينشر الناتج في إصدار `apk-latest` وكـ artifact للتشغيل.

بدلًا من الرفع، يمكن تشغيل سير العمل يدويًا من تبويب **Actions** مع تمرير
رابط تنزيل مباشر في الحقل `apk_url`.

> لماذا هذا المسار؟ لأن `KayPro/` فكّ تجميع **ناقص**: عشرة مكوّنات معلنة في
> الـ Manifest لا ملف مصدر لها إطلاقًا، فإعادة الترجمة مستحيلة.
> التفاصيل في [`docs/ENGINE_RECOVERY.md`](../docs/ENGINE_RECOVERY.md).
